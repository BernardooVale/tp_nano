# Artigo Científico em LaTeX (`artigo/`)

Esta pasta contém o artigo científico em duas versões idiomáticas autocontidas (prontas para compilação local com MiKTeX ou upload direto no Overleaf):

- [`pt/`](./pt/README.md) — **Versão em Português** (`main.tex`, `secoes/`, `figuras/`, `referencias.bib` e `main.pdf`).
- [`en/`](./en/README.md) — **English Version** (`main.tex`, `sections/`, `figures/`, `references.bib` and `main.pdf`).

Em ambas as versões, **Introdução / Introduction** e **Referencial Teórico / Theoretical Background** estão estruturados como *placeholders* para redação posterior, enquanto **Metodologia / Methodology**, **Resultados / Results** e **Conclusão / Conclusion** estão integralmente redigidos.
